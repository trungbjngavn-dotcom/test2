# Descent: Cell to Quantum Field

A self-contained JavaScript (Canvas 2D) animation: one continuous zoom from an *E. coli* bacterium down through its cytoplasm, the transcription–translation machinery, the atomic DNA double helix, a G≡C base pair, a carbon atom's electron cloud, the carbon-12 nucleus, a proton, and finally quantum fields.

Open `index.html` in any modern browser. No dependencies or network needed.

**Controls:** `Space` pause · `←/→` chapters · `R` restart · click chapter names on the right-hand scale.

Distances are to scale. Motion is slowed and structures simplified for clarity.
